<h1 align="center">Artificial Intelligence</h1>

<p align="center">
  Beginner-friendly Python examples demonstrating fundamental AI concepts chapter by chapter.
</p>

---

A collection of beginner-friendly Python programs that demonstrate the core concepts of Artificial Intelligence while learning Python fundamentals.

Each chapter introduces a Python topic alongside a practical AI concept, allowing readers to understand both programming and machine learning step by step.

## Chapters

### Chapter 1 – Variables
- Artificial Neuron
- Weighted Sum

### Chapter 2 – For Loops
- Gradient Descent
- Learning a model's weight through iterative optimization

### Chapter 3 – Numbers
- Euclidean Distance
- Distance calculation used in k-Nearest Neighbors (k-NN)

### Chapter 4 – If Statements
- Single-layer Perceptron
- Threshold Activation Function

### Chapter 5 – Miscellaneous Topics I
- Manual Nearest Neighbor Search
- Finding the closest data point without lists

### Chapter 6 – Strings
- Simple Sentiment Analysis
- Bag-of-Words approach using string operations

### Chapter 7 – Lists
- k-Nearest Neighbors (k=1)
- Automatic nearest neighbor search using lists and loops
